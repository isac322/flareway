Flareway {{ .Chart.AppVersion }} is installed in {{ include "flareway.namespace" . }}.

Prerequisite: install the Gateway API v1.6.3 standard CRDs before creating a GatewayClass or Gateway:

  kubectl apply --server-side -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.6.3/standard-install.yaml

{{- if not .Values.gatewayClass.create }}
The chart did not create a GatewayClass. After you create a CloudflareAccount, create it with:

  helm upgrade {{ .Release.Name }} oci://ghcr.io/isac322/charts/flareway --version {{ .Chart.Version }} --namespace {{ include "flareway.namespace" . }} --reuse-values \
    --set gatewayClass.create=true --set gatewayClass.config.accountRefName=<CloudflareAccount name>
{{- end }}

The chart bundles only Flareway CRDs. Helm retains CRDs and the system namespace on uninstall.
Uninstalling the chart therefore does not delete Flareway custom resources or trigger their remote deletion policies.
No uninstall hook contacts Cloudflare or deletes remote state.

{{- if and .Values.metrics.enabled .Values.metrics.secure }}
The metrics endpoint requires Kubernetes authentication and authorization. Bind the ClusterRole
{{ include "flareway.fullname" . }}-metrics-reader to each scraping ServiceAccount.
{{- end }}
